# Lumo 翻译

轻量级 Windows 翻译工具。**单文件 exe，双击即用，不需要装任何东西。**

```
Lumo.exe      71 MB   自包含单文件，含 .NET 运行时
install.bat            可选：装到「%LOCALAPPDATA%\Programs\Lumo」并创建开始菜单快捷方式
```

## 为什么是这个方案

同类翻译工具大多在「常驻」这件事上很重。Lumo 用 **.NET 9 + 原生 WinForms**，
GDI 绘制，不带任何浏览器内核：

| | Electron 类 | Chromium 内核 | **Lumo** |
|---|---|---|---|
| 空闲内存 | 120–200 MB | 80–120 MB | **约 30–45 MB** |
| 安装包 | 80–150 MB | 40–80 MB | 71 MB（含运行时） |
| 首次启动 | 下载 Chromium | 下载 WebView2 | **无需下载** |

几个刻意的取舍：

- **不用 WebView2。** 渲染进程空闲就吃 50–80 MB，套上它等于绕回 Electron，
  「低资源占用」这个前提直接作废。所以界面是纯 WinForms 手写布局。
- **不捆绑 OCR 模型。** 截图翻译走 Windows 自带的 `Windows.Media.Ocr`，
  不带几百 MB 的识别模型，也不吃 CPU。
- **不装全局键盘钩子。** 剪贴板监听用 Windows 定时器轮询内容，
  空闲时开销可以忽略。
- **没引 SQLite。** 纯 JSON + 有界 LRU，省掉一个原生依赖和一份数据库文件。

> **关于 71 MB：** 这是自包含（把 .NET 运行时一起打包）的代价，买的是
> 「不用装任何东西」。如果你已经装了 .NET 8/9 Desktop Runtime，
> 框架依赖版只有 1 MB 左右 —— 但本项目只提供了自包含版，
> 省不下你装运行时的 55 MB，所以直接给了自包含。

## 功能

**取词**
- 在任意程序里选中文字，按 `Alt+D` 翻译
- 复制即翻译（带防抖和内容去重，不会被自己回填的剪贴板触发）
- **托盘菜单里可随时开关剪贴板监听** —— 复制密码之类的时候不想被打扰，右键托盘关掉即可
- 译文可一键回填到原窗口，也可在窗口内交换原文/译文

**截图**
- 框选屏幕区域 → 系统 OCR → 直接翻译
- DPI 感知，125%/150% 缩放屏幕下框选位置不偏
- 选区过小/过大在请求前就拦下，不浪费一次 OCR

**引擎**（可自定义，设置里点一下就切）
- **微软 Edge**（免 Key，默认）—— 用 Edge 浏览器内置的翻译端点，国内可直连
- Google 翻译（免 Key）—— 国内通常不通，配了代理才有意义
- DeepL（免费版/专业版按 key 后缀自动识别）
- OpenAI 兼容 —— DeepSeek、Kimi、Ollama、LM Studio 都能接
- 自定义 HTTP —— 用 `{{text}}` / `{{from}}` / `{{to}}` / `{{key}}` 模板描述任意 API

> **为什么默认是 Edge：** 微软在 2026 年 8 月下线了旧的免鉴权 auth 端点
> （`edge.microsoft.com/translate/auth`，现在固定 404），免费路径改到了
> Edge 内置翻译的 `translatetext` 端点。这个端点不需要鉴权，
> 而且 `edge.microsoft.com` 在国内不墙 —— 是目前少数「免 Key + 国内可用」的方案。

主引擎失败自动回退到备选。401/403 这类鉴权错误不触发回退 —— 换引擎也解决不了
Key 无效，直接报错更快。

**其他**
- 历史记录：搜索、收藏；收藏项不会被容量淘汰
- 翻译缓存：带 TTL 的有界 LRU，键含引擎和语言方向，不会串味
- 迷你化、暗色（跟随系统）、窗口透明度、代理配置

## 三个主要操作

| 想做什么 | 怎么做 |
|---|---|
| 翻译一段选中的文字 | ① 在任意程序里**用鼠标划选**一段文字 → ② 按 `Alt+D` |
| 翻译屏幕上的画面 | 按 `Alt+O` → 拖动鼠标框选区域 |
| 复制即自动翻译 | 托盘菜单里勾选「监听剪贴板」；复制密码之类不想被打扰时从同一处关掉 |

首次启动会弹一次使用说明，**里面有「下回不再提示」的勾选框**，勾了之后就不再打扰。
想随时回看：**设置 → 使用说明**（还有一个「重新显示首次提示」按钮）。

托盘菜单只保留「显示主窗口 / 截图翻译 / 监听剪贴板开关 / 设置 / 退出」。
「翻译选中文字」不在托盘里 —— 它必须配合划选和快捷键使用，
做成菜单项反而让人以为点了就能翻译；快捷键就写在主窗口状态栏和说明页里。

## 快捷键

| 默认 | 作用 |
|---|---|
| `Alt+D` | 翻译选中文字（**先在任意程序里划选一段文字**，再按此键）|
| `Alt+O` | 截图翻译 |
| `Alt+M` | 显示 / 隐藏窗口 |
| `Ctrl+Enter` | 窗口内翻译 |
| `Esc` | 取消框选 |

全部可在「设置 → 快捷键」改。

## 安装

**方式一：绿色版（最简单）**

把 `Lumo.exe` 随便放哪，双击运行。零依赖。

**方式二：安装**

双击 `install.bat`。会装到 `%LOCALAPPDATA%\Programs\Lumo` 并创建开始菜单快捷方式。

```bat
install.bat /silent          :: 静默安装，供自动化部署
install.bat uninstall        :: 卸载
```

卸载默认保留设置和历史（在 `%APPDATA%\Lumo`），要彻底重置就自己删掉那个文件夹。

## 系统要求

- Windows 10 1809（17763）及以上，或 Windows 11
- 64 位
- 无需 .NET、无需 WebView2

## 配置

第一次运行会在 `%APPDATA%\Lumo\` 下创建：

| 文件 | 内容 |
|---|---|
| `config.json` | 所有设置，原子写入，损坏时自动归档为 `.corrupt` |
| `history.json` | 翻译历史，按条数上限裁剪，收藏项永不淘汰 |

API Key 只保存在本地配置文件，不上传任何地方。

### 开机自启

「设置」里没有这个开关，手动加一下快捷方式最省事：

```
Win+R  →  shell:startup
```

在打开的文件夹里右键 → 新建快捷方式 → 指向 `Lumo.exe`。

## 已知限制

- **OCR 语言包**：Windows 只预装少量 OCR 语言，其他需要在
  「设置 → 时间和语言 → 语言和区域」里补装。没装时程序会明确提示，不会静默失败。
  「设置 → 关于」页会列出当前已装的语言包。
- **混合语言段落**：翻译 API 的源语言只能有一个，整段交给服务只会按主导语言
  处理、原样返回。程序会**自动按语言切段**，只翻「非目标语言且成规模」的片段，
  其余（已是中文的、术语、品牌名）原样保留后拼回。换行和缩进完整保留。
  例如中英日西四种语言混排的一整段，会被拆成 30+ 段，其中 14 段送去翻译，
  其余（中文、PDF、DOAJ、Google Scholar、arXiv 等）原样保留。
  日文靠「含假名」识别，并和相邻汉字合成完整短语后整体翻译。
  代价是一次请求变成两三次；界面上会标注「N 段已翻译，M 段保留原文」。
- **UIAutomation 覆盖率**：Electron 应用（VSCode、Slack 等）、部分游戏、
  RDP 断开状态下可能取不到选区。这种时候用剪贴板路径（复制即翻译）仍然有效。
- **Google 免费端点**没有稳定性承诺，国内通常不通，配额也有限。
  设置里可填 Cookie 提高配额，或改用默认的 Edge / DeepL / OpenAI 兼容。
- **只支持 Windows x64。**

```bat
dotnet test

  -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true ^
  -p:EnableCompressionInSingleFile=true ^
```

### 两个值得一提的设计

**引擎的 `Build` / `Parse` 拆成纯函数。** 每个引擎把「怎么发请求」和
「怎么读响应」拆开，只有中间的网络往返是不确定的。于是请求构造和响应解析
都能用固定样本离线测试 —— Google 返回多段句子时中文要不要加空格、
Bing 的响应是「请求项数组套 translations 数组」这种坑，都是靠单测钉住的，
不用真发一次请求。

**OCR 脚本模板放在 core 而不是 App 层。** 那样它能被单元测试覆盖 ——
这个脚本是纯字符串拼接，没有 Windows 依赖，却是最容易出静默错误的地方。

**关于 OCR 为什么走 PowerShell 子进程：** 用的是完全相同的系统 OCR，
识别率零损失；换来的好处是这段代码脱离 Windows 也能编译和测试。
代价约 300–600ms 进程启动 —— 截图翻译是用户主动触发的低频操作，这代价可接受。
⚠ 必须用 `powershell.exe`（5.1），**不能用 `pwsh`**，PS7 移除了 WinRT 类型投影。

## 踩过的坑（供后来人参考）

写 `ScriptOf` 的字符区间时，把 CJK 兼容汉字的起点 `U+F900` 写成了 `U+8C48`，
汉字范围被撑到 `U+FAFF`，**把整个谚文区 `U+AC00..U+D7AF` 都吞了进去**，
韩语被误判成中文。现在所有区间端点一律用 `\uXXXX` 显式转义写进源码，
不用字符字面量 —— 编译器还会帮忙验证区间不重叠。

BMP 编码器最初每写完一行按 `width*3` 跳到下一行，**跳过了 4 字节对齐的填充**，
下一行像素直接盖在填充字节上。`PadsRowsToFourBytes` 这个测试当场抓到了。
